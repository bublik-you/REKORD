# REKORD — после пар

Интерактивная пиксельная карта района НГТУ НЭТИ в Новосибирске. Основа для будущей презентации, без слайдов и сюжетного наполнения.

## Запуск

Статический сайт, без сборки и зависимостей. Обслуживать каталог `dist` любым HTTP-сервером, например:

```sh
python -m http.server 8080 --directory dist
```

Открыть `http://localhost:8080`. Нельзя открывать HTML напрямую через `file://`: карта загружается из JSON.

## Управление

- Выбор НГТУ, Burger King или Молочая в меню либо на карте.
- Четыре персонажа идут по пешеходному графу OpenStreetMap. Пауза, продолжение, повтор маршрута.
- Перетаскивание карты, масштаб колесом / кнопками / жестом двух пальцев, возврат к общему виду, полный экран.
- Выбор отдельного персонажа подсвечивает его номер.
- При фокусе на карте: пробел — пауза, стрелки — перемещение, +/− — масштаб, 0 — общий вид, Escape — закрыть карточку.

## География и источники

План улиц, контуры зданий и пешеходные пути: © участники [OpenStreetMap](https://www.openstreetmap.org/#map=18/54.9887/82.9053), [ODbL](https://www.openstreetmap.org/copyright). Набор производных координат находится в `dist/map-data.json`. Проекция локальная, карта повёрнута примерно на 44°, масштаб и оформление условные. Это творческая схема, не навигатор.

- [Официальная карта кампуса НГТУ](https://en.nstu.ru/upload/medialibrary/acc/accfb1662a37dfcd4336aeb09ecc5902.pdf).
- [Burger King, Геодезическая](https://yandex.com/maps/org/burger_king/1373417535/). В OSM адрес: Геодезическая 13А; в Яндекс Картах указан 13.
- [Молочай, Геодезическая 4/1, этаж −1](https://yandex.kz/maps/ru/org/molochay/154149459081/?lang=ru). Точка внутри ТЦ «Амстердам»; маршрут ведёт до ТЦ, внутренний план не воспроизведён.

Данные проверены 15 ноября 2026. Деревья, мелкие детали и персонажи условные. Шрифты Pixelify Sans и Golos Text распространяются по SIL Open Font License.

## Файлы

`dist/index.html` — интерфейс; `dist/style.css` — стили; `dist/app.js` — рисование, камера и взаимодействия; `dist/map-data.json` — геометрия. `.openai/hosting.json` — привязка частного сайта.
